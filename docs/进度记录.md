## 八、已解决的坑（避免重复踩）

1. **`pytest.ini` 中文注释在中文 Windows 崩** —— iniconfig 按系统 GBK 读 .ini，报 `UnicodeDecodeError`。
   配置统一写在 `backend/pyproject.toml`（TOML 按 UTF-8 解析）。已写入 CLAUDE.md §9。
2. **`python_files` 必须含 `pytest_*.py`** —— CLAUDE.md 硬约束 3 规定的文件名不匹配 pytest 默认的 `test_*.py`，
   不配置会「no tests ran」。
3. **习题模板原先不要求 `score` 字段** —— 实测 23 道题分值全为 `None`，教师得手工补。
4. **试题模板手写「总分 100 分」但分项相加只有 90** —— 已改为由 `DEFAULT_EXERCISE_SPEC` / `DEFAULT_EXAM_SPEC`
   经 `_spec_line()` 生成题量与总分，文案与分值无法再脱节。上面 3、4 两条都有 `TestPromptSchema` 用例守着。
5. **`EventSource` 只支持 GET** —— 生成接口是 POST + JSON body，故前端用 `fetch` + `ReadableStream`
   手写 SSE 帧解析，同样逐块消费。理由写在 `frontend/src/api/lesson.js` 顶部注释。
6. **Python 读写文件一律显式 `encoding="utf-8"`** —— 连临时分析脚本也一样，否则中文 Windows 上默认 GBK 直接报错。
7. **重启后端要按 PID 杀** —— `taskkill` 按窗口标题过滤常常杀不掉，旧进程仍占 8000，
   新进程静默启动失败（`error while attempting to bind`），结果调试的是旧代码，白折腾一轮。
8. **numpy 2.x 与 conda 编译的 scipy/sklearn/pandas 不兼容**（工单18 期间修复）——
   `import sklearn` 直接 `ImportError: numpy.core.multiarray failed to import`，
   连 `sentence_transformers`、`transformers`（`generation.utils` 里 import sklearn）都被拖垮。
   修法：`pip install -U scipy scikit-learn pandas -i https://pypi.tuna.tsinghua.edu.cn/simple`
   （装 numpy 2 版轮子覆盖 conda 版，**不要降级 numpy**，很多新包已要求 numpy>=2）。
   副作用：`gensim 4.3.3` 声明 `numpy<2`，本就用不了，本项目不依赖它。
9. **本地 Embedding 不走 sentence-transformers** —— 依赖链长（sklearn/scipy/pandas），
   改为 `transformers` + `torch` 手写 CLS 池化 + L2 归一化，实测与官方实现数值一致（差异 3e-8）。
   代码在 `app/services/embedding.py::_embed_local`，切换只改 `.env` 的 `EMBEDDING_PROVIDER=local`。
10. **换 Embedding 模型必须重建向量库** —— 云端 bge-m3 是 1024 维、本地 bge-small 是 512 维，
    Chroma 的 collection 维度建库即固定。已加 `.embedding_signature.json` 签名文件：
    写入前拦截并给出「删 data/chroma 重新解析」的提示，召回侧自动降级为关键词召回。
11. **Vite 代理目标必须写 `127.0.0.1` 而不是 `localhost`**（工单18 期间修复）——
    Vite 监听 `[::1]:5173`，Node 把 `localhost` 解析到 IPv6 的 `::1`，
    而 uvicorn 默认只监听 IPv4 `127.0.0.1:8000`，结果前端所有 `/api` 请求 502。
12. **本机 shell 有系统代理**（`HTTP_PROXY=http://127.0.0.1:7897`）——
    用 curl 测本地端口会得到代理返回的 **502**，看着像服务挂了其实是没连上。
    本地自测加 `curl --noproxy '*'`，python 脚本用 `httpx.Client(trust_env=False)`。
13. **PyMuPDF 抽的表格/文本会带 HTML 实体**（`&amp;#45;` 之类）——
    解析器里统一 `unescape_entities()` 清洗；测试用例也据此断言。
14. **公式识别是保守启发式** —— 只把「无中文 + 含数学符号 + 运算符密度达标」的行判为公式块，
    纯 ASCII 公式（`y = wx + b`）按正文入库（仍可被检索到），宁可漏判不误判。
15. **判断后端跑的是不是最新代码，看 `/openapi.json` 而不是看进程在不在**（工单19 收工前实测踩到）——
    8000 端口明明 LISTENING，人也在 `curl /docs` 拿到 200，但那是**工单19 之前启动的旧进程**，
    `/api/learn/*` 一条都没有，前端页页 404。一条命令就能确认：
    `curl -s http://127.0.0.1:8000/openapi.json | python -c "import sys,json;print(len(json.load(sys.stdin)['paths']))"`
    （当前应为 **43**）。杀旧进程用 `taskkill //F //PID <PID>`，重启加 `--reload` 免得再来一次。
