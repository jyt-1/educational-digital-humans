# 育智平台 · 完整使用讲解

> 平台名：**育智平台 —— AI 教学智能体**
> 四大能力：智能备课 · 智能助教 · 个性化学习 · 数字人形象层
> 本手册面向平台的所有使用者（教师为主），按"第一次拿到平台怎么用"的顺序完整讲一遍。
> 版本：2026-09-20

---

## 〇、平台是什么

育智平台是一个面向高职教师的 **AI 教学工作台**，围绕"备课 → 上课 → 课后辅导 → 学生自学"整条链路：

1. **智能备课**：教师输入课程信息，AI 流式生成教案 / 课件 / 习题 / 案例 / 试题，可在线编辑、版本管理、一键导出 docx / pptx；
2. **智能助教**：教师上传教学资料建知识库，AI 数字人基于资料做**带引用溯源**的流式问答，支持语音提问；
3. **虚拟教室**：把备课内容一键"成课"，生成**数字人讲课视频**（真人口型同步），学生可随时观看；
4. **个性化学习**（学生侧）：基于知识点画像的自适应练习、学习路径推荐、AI 错题分析。

**角色说明**：注册时选「教师」或「学生」。
- **教师**：可用智能备课全部功能（生成 / 成课 / 知识库上传）、查看学生侧页面；
- **学生**：以个性化学习为主（练习 / 错题本 / 学习路径），可检索公共知识库、观看讲课视频，**不能**使用智能备课生成（页面内会提示降级）。

顶栏右上角有角色 Tag（教师=绿色 / 学生=灰色），注意别登错号。

## 二、智能备课（教师核心工作区）

### 2.1 内容生成 —— AI 帮你写教案/课件/习题

**位置**：智能备课 → 内容生成。

**操作流程**：填参数 → 点「生成」→ 右侧流式输出（生成中可「中断」）→ 满意后保存为备课记录。

**参数详解**（这里最容易踩坑，务必看）：

| 字段 | 作用 | 填法建议 |
|---|---|---|
| 内容类型 | 决定生成什么 | 教案 / 课件 / 习题 / 案例 / 试题 五选一 |
| **课程名** | ⭐ **决定 AI 生成的内容主题** | 填真正的授课内容：「大学语文」「人工智能导论」「《劝学》」 |
| 学科/专业 | 仅作分类标签，**不参与内容生成** | 「语文」「工科」等大类 |
| 章节 | 让内容聚焦到某一讲 | 「第1课 背影」「第3章 神经网络」 |
| 知识点 | 进一步收窄范围 | 可多个，回车添加：「比喻论证、细节描写」 |
| 难度 | 简单 / 中等 / 困难 | 按学情选 |
| 教学目标 | 明确产出导向 | 回车添加多条 |
| 补充要求 | 自由文本约束 | 如"多举企业实例""结合高职学情" |

> ⚠️ **最重要的一条**：**课程名决定 AI 讲什么，学科只是贴标签。**
> 课程名填「人工智能导论」、学科填「语文」→ 生成的全是人工智能内容。
> 想要哪门课的内容，就把课程名写成那门课。

> 💡 内容质量的上限取决于你填得多具体：只填"语文 + 章节 1"会泛泛而谈；
> 填到具体课文 + 知识点（如《念奴娇·赤壁怀古》+ 豪放词风格），产出才有的放矢。

**五种类型分别长什么样**：
- 教案 / 案例：Markdown 正文（教学目标、重难点、教学过程等结构）；
- 课件：结构化幻灯片（每页标题 + 要点 + **讲稿备注**），备注后续直接用于成课；
- 习题 / 试题：结构化题目（题干 / 选项 / 答案 / 解析 / 知识点 / 分值），入库后供学生端自适应练习抽取。

### 2.2 我的备课 —— 记录管理与二次加工

**位置**：智能备课 → 我的备课。

- 列表展示全部备课记录（支持按内容类型、课程名筛选）；
- **打开方式：点击行任意位置**，或右侧固定的「编辑」按钮（窗口窄时操作列固定在最右，不会被滚动条藏住）；
- **编辑页**：
  - 教案/案例：Markdown 编辑 + 预览切换；
  - 课件：逐页编辑（标题/要点/讲稿备注），可增删页面；
  - 习题/试题：结构化题目编辑器；
  - 右侧**版本历史**：每次保存生成新版本，可一键回滚（回滚不删历史，是追加新版本）；
- **导出**：教案/案例/习题/试题 → **docx**；课件 → docx + **pptx**（讲稿备注写入 pptx 备注区，不上幻灯片）。注意：导出的是**已保存版本**，有未保存修改时先保存。

### 2.3 成课 —— 把备课内容变成数字人讲课视频 ⭐

**哪些内容能成课**：
- **教案**：按 `## ` 标题自动拆页，正文转讲稿底稿；
- **课件**：每页一条讲稿，**优先使用每页写好的「讲稿备注」**（没有备注的页会用标题+要点拼底稿，可在弹层里改写）；
- 习题/试题不支持（题目列表没有可"讲"的叙事文本）。

**操作**：我的备课 → 教案或课件行 → 点「**成课**」→ 弹层中确认课程名 / 学科 / **数字人形象**、逐段核对修改讲稿 → 「提交生成」。

**生成过程须知**：
- 生成走 **CPU 离线管线**（Edge-TTS 合成语音 + Wav2Lip 逐帧口型同步）：
  一段讲稿约几十秒，整课（如 15 段）约 **5~8 分钟**；
- **一次只允许一个生成任务**，期间再提交会提示"已有生成任务在进行中"——等第一个完成即可；
- **生成期间保持弹窗开启**以看到进度；
- 讲稿配音用微软 TTS，遇网络瞬断**自动重试（最多 5 次、约 70 秒窗口）**；
  若最终失败，等一两分钟重新提交即可（常见于无线网络抖动）；
- 完成后视频自动出现在「数字人讲课」页的课程下拉里。

## 三、虚拟教室（数字人讲课）

**位置**：虚拟教室 → 数字人讲课。

- **课程下拉** = 内置示例课（"天空为什么是蓝色的？"，平台自带演示）+ 全部成课产物；
- 课程列表**不是预置课程库**——哪门课出现，取决于你用哪门课的内容走过成课。
  想要语文课，就用语文的教案/课件成课；想要数学课，同理；
- **播放器能力**：
  - 数字人视频 + 课件页联动：讲稿引擎按时间轴**自动翻页 + 字幕同步**；
  - 点页码圆点跳转到对应讲段，进度条随意拖动；
  - 课件正文支持 Markdown 与 KaTeX 公式（`$...$`）渲染。

## 四、智能助教

### 4.1 知识库 —— 先喂资料，AI 才有得引用

**位置**：智能助教 → 知识库。

- **支持格式**：PDF / Word / PPT / Excel / 图像，单文件 ≤ 50MB；
  解析能力：表格转 Markdown、图片抽取、公式保留；
- **公共库 / 私有库**双 Tab：
  - 公共知识库：师生都可检索，仅教师可上传；
  - 我的私有库：仅本人可见可用（适合放个人教案、内部资料）；
- **状态流转**：排队中 → 解析中 → 已完成 / 解析失败（页面 2 秒轮询自动刷新）；
  **只有「已完成」的文档才会被检索到**；
- 操作：上传文档 / 详情（内容块预览+统计）/ 重新解析 / 删除。

### 4.2 智能问答 —— 带引用溯源的数字人答疑

**位置**：智能助教 → 智能问答。

- 布局：左侧会话管理 + 检索设置，右侧数字人舞台（写实形象、口型/眨眼随语音驱动、状态胶囊：待命中/倾听中/思考中/回复中）；
- **会话**：可新建 / 切换 / 删除，会话按账号隔离；
- **检索设置**（每次提问前可选）：
  - 范围：全部知识库（公共+私有）/ 仅公共 / 仅我的私有库；
  - 重排：跟随配置 / 强制重排 / 关闭重排；
- **回答**：SSE 流式输出，**边生成边朗读**（数字人开口讲）；
  答案中的 **[n] 角标**可点击 → 右侧「引用来源」抽屉自动展开并高亮对应出处，**每句话都能溯源到知识库原文**；
- **闲聊与自我介绍**：打招呼、问「你是谁 / 你会什么」这类**不走知识库**——
  数字人会**用它自己的身份和性格**回答（小满俏皮、晓雯温和、陈远直率……换形象话术跟着换），
  不会甩给你一屏「知识库中未找到依据」。空会话时左侧还会先显示当前形象的开场白；
- **语音提问**：点麦克风说一句，说完自动发送（需 Chrome/Edge 浏览器）。

### 4.3 检索调试 —— 问答质量的诊断台

**位置**：智能助教 → 检索调试。**排查工具，日常不用管。**

它把问答背后的检索管线完整暴露：向量语义召回（bge-m3）+ 关键词召回（BM25/jieba）→ RRF 融合排序 → 可选云端重排（bge-reranker-v2-m3）。

**用法**：问答答得不好时，来这里输入**同一个问题**（不生成答案，只看检索命中），对照下表定位问题：

| 现象 | 结论 | 对策 |
|---|---|---|
| 一条都没召回 | 资料没覆盖 / 文档没解析完 | 补传资料，检查解析状态 |
| 召回了正确片段 | 资料没问题 | 换更贴近资料原文的问法 |
| 正确片段排序靠后 | 排序问题 | 强制开启重排、调大 Top K |

可调参数：检索范围、Top K、重排开关——改完立刻重查，做对比实验。

## 五、个性化学习（学生侧）

学生登录后主要使用以下页面（教师账号打开会显示提示条）：

- **学习仪表盘**：知识点掌握度雷达图（最薄弱 12 项）、统计卡（已评估知识点/平均掌握度/薄弱点/待复习错题）、**今日任务**（"最该补"的知识点 + 一键开始练习）；
- **学习路径**：按步骤推荐的学习时间线（每步：知识点、当前掌握度、推荐理由），直达练习；
- **练习与试卷**：
  - **练习模式**（训练）：按知识点取题，**连对 3 题自动升难度档**，即时判分反馈；
  - **试卷模式**（测量）：取最近一套试卷作答、交卷算分，不影响难度档；
  - 答错自动进入 AI 错题分析；
- **错题本**：按知识点筛选；每道错题有**作答对照 + AI 分析**（错误原因诊断，标注"命中常见误区预设/现场推断"）+ **变式题**（再错会重新分析）+ 相关知识点三出口（去练习/相关学习）；
- **历史成绩导入**：上传 Excel（提供模板）或手工录入，失败行会标明原因，支持整批撤销。

> 闭环关系：教师备课时生成的**习题/试题会入库**，成为学生自适应练习的题源——
> 备课质量直接影响学生端练习体验。

## 六、数字人形象与声音

- 平台内置 **7 个数字人形象**：晓雯（默认）、苏青、周慧、林悦、陈远、吴谦（写实照片级）+ 小满（二次元 Live2D）；
- 每个形象**绑定默认音色**（如晓雯=晓晓女声、陈远=云健男声），切换形象自动跟随，也可在设置里手动改音色；
- **试听**：形象设置弹层的音色旁有「试听」按钮，点一下就用当前音色 + 当前形象的嗓音调性念一句话——
  换音色、换形象后先试听再确认，不用等到问答/成课才发现声音不对；
- 每个形象有**自己的人设与开场白**：问答页空会话时它先开口打招呼；问它「你是谁 / 你会什么」会用各自的身份回答；
- **小满自带「萌音」**：切换到她时会自动应用 音调 +30Hz、语速 +8%（面板音色旁会有「萌音」标记）。
  这是因为微软中文音色里没有儿童/萌系嗓音，萌感由音调参数塑造；不需要可在音色下拉里换回其他音色；
- 形象可在**智能问答舞台**（实时问答）与**成课视频**（离线讲解）中使用——成课弹层里直接选形象。

### 6.1 声音定制能到什么程度

| 方式 | 效果 | 现状 |
|---|---|---|
| 换内置音色 | 8 个中文音色（晓晓/晓伊/云希/云健/云扬/云夏/东北话/陕西话） | ✅ 已可用 |
| 音调/语速微调 | 塑造"萌音""沉稳"等嗓音调性（小满即用此法） | ✅ 已支持（形象级配置） |
| **克隆你自己的声音** | 上传几秒录音，数字人用你的声线讲课/答疑 | ⏳ 待拍板（见下） |

**声音克隆的两条路**（本项目机器无独立显卡，这是关键约束）：

| 路线 | 方案 | 代价 |
|---|---|---|
| 本地部署 | GPT-SoVITS / CosyVoice / Fish Speech（社区明确支持 CPU 推理） | 免费、数据不出本机；但**CPU 慢**：适合成课离线出片，实时问答跟不上 |
| 云端 API | 阿里百炼 CosyVoice 音色克隆 / 微软 Azure 自定义语音 / 腾讯云 | 实时可用、质量稳定、有免费额度；需注册采购、声音数据上云 |

> ⚖️ **合规提醒**：只能克隆**本人或已获授权**的声音（他人声音受人格权保护），
> 且合成音频对外发布时需按要求标识。

## 八、常见问题速查

| 问题 | 原因 / 解法 |
|---|---|
| 我的备课"点不开" | 点**行任意位置**或右侧固定的「编辑」按钮 |
| 生成的内容主题不对 | 检查**课程名**——它决定内容；学科只是标签 |
| 想要语文/数学等课程 | 用该课程内容走一遍"生成 → 成课"，课程下拉即会出现 |
| 成课提示"已有生成任务在进行中" | 上一个任务还在跑，等它完成（约 5~8 分钟） |
| 成课失败：TTS 连接失败 | 网络瞬断；管线已带 5 次自动重试，仍失败等一两分钟重提 |
| 知识库文档没被检索到 | 确认解析状态为「已完成」；或问题措辞离资料原文太远 |
| AI 回答没有引用/不可信 | 检查提问范围是否选对（私有库 vs 公共库）；先去检索调试确认资料命中 |
| 语音提问没反应 | Web Speech 仅 Chrome/Edge 支持，注意浏览器麦克风权限 |
| 问数字人"你是谁"答非所问 | 已支持：闲聊/自我介绍按当前形象的人设回答；若答得像检索结果，说明问题里混了知识型内容（如"介绍下反向传播"） |
| 数字人嘴型不动/不同步 | 刷新页面重进；仍不行检查朗读开关是否打开（静音时口型不驱动） |
| 学生看不到备课菜单功能 | 智能备课仅教师可用，属正常设计 |
| 「天空为什么是蓝色的？」哪来的 | 平台内置示例课 |
